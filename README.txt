==========================================================
BOT - ИНСТРУКЦИЯ ПО УСТАНОВКЕ
==========================================================

ОПИСАНИЕ:
Модульная система для обучения английскому языку через Telegram
с использованием искусственного интеллекта Polza.ai.

ТРЕБОВАНИЯ:
1. Python 3.13 ONLY.
2. FFmpeg (обязательно для обработки голосовых сообщений).
   - Скачать: https://ffmpeg.org/download.html
3. API Ключ от Polza.ai и Токен Telegram бота (от @BotFather).

БЫСТРЫЙ СТАРТ:
1. Распакуйте архив с ботом в рабочую папку.
2. Создайте файл .env в корневой папке и заполните его:
   BOT_TOKEN=ваш_токен
   ADMIN_IDS=ваш_id_телеграм
   POLZA_API_KEY=ваш_ключ_ai
3. Запустите установщик (install.bat или setup.sh).
4. Запустите бота: run.bat


ПОДДЕРЖКА:
Данная система работает локально. Все данные хранятся в 
файле lingua_data.db. Не удаляйте его, чтобы не потерять прогресс.
